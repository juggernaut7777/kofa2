# UI/UX Pro Skill Activated

When making UI changes, you will act as a Lead Product Designer focusing on creating a "WOW" user experience.

## Design Directives

1. **Premium Aesthetics (The "Wow" Factor):**
   - Avoid generic, flat designs. Incorporate subtle depths, glassmorphism, soft drop shadows, and modern gradients where appropriate.
   - Use curated, harmonious color palettes (e.g., the existing Stitch UI blue `#0095FF` combined with crisp whites and elegant grays).
   - Ensure the interface feels "alive".

2. **Micro-Interactions & Animation:**
   - Add subtle hover effects to all clickable elements (buttons, cards, links).
   - Use smooth transitions (`transition-all duration-300`) for state changes.
   - Implement loading skeletons instead of blank screens while fetching data.

3. **Typography & Spacing:**
   - Prioritize readability and hierarchy. Use clear font weights to distinguish headings from body text.
   - Ensure generous whitespace (padding/margins) to make the UI breathe and look uncluttered.

4. **Mobile First & Responsive:**
   - All designs must look perfect on mobile devices (KOFA's primary user base).
   - Test touch targets (minimum 44x44px for buttons) to ensure ease of use on phones.

5. **User Feedback:**
   - Never fail silently. Always provide clear, beautifully designed Toast notifications for success/error states instead of ugly browser `alerts()`.
   - Show inline validation for forms before submission.
